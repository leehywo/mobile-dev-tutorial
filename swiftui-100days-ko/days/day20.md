## 핵심 개념 해설

### ZStack으로 배경과 콘텐츠 층을 겹치기

ZStack의 먼저 선언된 색은 뒤의 콘텐츠 아래에 놓이며 ignoresSafeArea는 배경만 안전 영역 밖까지 확장합니다. 값이 만들어지는 지점, 수정 권한을 가진 코드, 최종 소비자를 순서대로 표시해 보세요. 도시 엽서 퀴즈처럼 익숙한 소재를 사용하면 문법보다 데이터 역할에 집중할 수 있습니다. 컴파일 성공이 도메인 규칙까지 보장하지는 않으므로 경계 입력도 함께 대입해야 합니다.

```swift
ZStack {
    Color.indigo.ignoresSafeArea()
    VStack(spacing: 18) {
        Text("이 엽서의 도시는?").font(.title.bold())
        HStack {
            Image("busan").clipShape(.rect(cornerRadius: 12))
            Image("jeonju").clipShape(.rect(cornerRadius: 12))
        }
    }
}
```

코드는 원문 예제를 옮기지 않고 도시 엽서 퀴즈 상황에 맞춰 새로 작성했습니다. 저장된 원본과 계산되는 값, 동작 뒤 바뀌는 값을 구분해 보세요.

### VStack과 HStack으로 퀴즈의 축 구성하기

수직 질문과 수평 선택지를 서로 다른 스택에 두면 화면의 두 축과 정보 계층이 코드에 그대로 나타납니다. 값이 없거나 형식이 틀리거나 범위를 벗어난 경우도 살핍니다. 임의의 기본값이나 강제 언래핑은 실제 원인을 숨길 수 있습니다. 화면 상태는 최소로 저장하고 나머지는 원본에서 계산해야 모순을 예방할 수 있습니다.

리뷰할 때는 값의 소유자, 변경 사건, 실패 뒤 표시를 질문하세요. 오늘의 도시 엽서 퀴즈 예제에서는 Image와 clipShape로 선택 가능한 국기 표현하는 과정이 그 접점입니다. 입력 타입과 출력 타입을 말로 이어 보면 판단 기준을 재사용할 수 있습니다.
