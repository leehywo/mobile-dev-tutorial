## 핵심 개념 해설

### if와 논리 연산자로 대출 가능 여부 판정하기

if의 조건은 나이 기준과 연체 여부가 동시에 만족되어야 한다는 업무 규칙을 그대로 읽히게 합니다. 값이 만들어지는 지점, 수정 권한을 가진 코드, 최종 소비자를 순서대로 표시해 보세요. 도서 대출처럼 익숙한 소재를 사용하면 문법보다 데이터 역할에 집중할 수 있습니다. 컴파일 성공이 도메인 규칙까지 보장하지는 않으므로 경계 입력도 함께 대입해야 합니다.

```swift
let age = 17
let overdue = false
if age >= 14 && !overdue { print("대출 가능") }
let section = "역사"
switch section {
case "역사": print("3층")
default: print("안내 데스크")
}
```

코드는 원문 예제를 옮기지 않고 도서 대출 상황에 맞춰 새로 작성했습니다. 저장된 원본과 계산되는 값, 동작 뒤 바뀌는 값을 구분해 보세요.

### switch로 여행 등급의 모든 경우 다루기

switch의 default는 알려진 서가 외의 입력도 반드시 처리해 실행 경로가 비지 않도록 합니다. 값이 없거나 형식이 틀리거나 범위를 벗어난 경우도 살핍니다. 임의의 기본값이나 강제 언래핑은 실제 원인을 숨길 수 있습니다. 화면 상태는 최소로 저장하고 나머지는 원본에서 계산해야 모순을 예방할 수 있습니다.

리뷰할 때는 값의 소유자, 변경 사건, 실패 뒤 표시를 질문하세요. 오늘의 도서 대출 예제에서는 삼항 연산자는 짧은 값 선택에만 사용하는 과정이 그 접점입니다. 입력 타입과 출력 타입을 말로 이어 보면 판단 기준을 재사용할 수 있습니다.
