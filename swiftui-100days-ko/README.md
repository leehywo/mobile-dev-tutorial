# 100 Days of SwiftUI 한국어 학습 동반 가이드

Swift를 처음 만나는 한국어 화자가 코드를 읽고 리뷰하는 힘을 기르도록 만든 오리지널 보조 자료입니다. JavaScript/TypeScript 경험을 발판으로 문법의 차이, SwiftUI의 데이터 흐름, 화면 구성 코드를 읽는 관점을 설명합니다.

원 강의는 Paul Hudson의 [100 Days of SwiftUI](https://www.hackingwithswift.com/100/swiftui)입니다. 이 저장소는 Hacking with Swift와 제휴하거나 승인을 받은 번역본이 아니며, **비공식 학습 보조 자료**입니다.

## 사용법

1. 그날의 [원문 강의](https://www.hackingwithswift.com/100/swiftui)를 먼저 학습합니다.
2. 같은 번호의 문서에서 한국어 해설과 새 예제를 읽습니다.
3. 코드를 실행하기보다 먼저 타입과 데이터 흐름을 말로 설명해 봅니다.
4. 접힌 확인 문제에 답한 뒤, 모르는 표현은 [용어집](glossary.md)에서 찾습니다.

각 문서는 원문의 문장이나 코드를 옮기지 않습니다. 링크된 강의의 학습 주제만 길잡이로 삼아, 설명과 예제를 별도로 작성했습니다.
