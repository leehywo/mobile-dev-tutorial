# Swift·SwiftUI 한국어 용어집

JS/TS 경험자가 Swift 코드를 읽을 때 자주 만나는 표현을 짧게 연결한 용어집입니다. “대응”은 이해를 위한 비유이며 두 언어의 동작이 완전히 같다는 뜻은 아닙니다.

| 용어 | 뜻 | JS/TS에서 떠올릴 것 |
|---|---|---|
| 변수(variable) | 다시 대입할 수 있는 이름 | `let` 변수 |
| 상수(constant) | 다시 대입할 수 없는 이름 | `const` |
| 타입(type) | 값이 허용하는 형태와 연산 | TS 타입 |
| 타입 추론 | 값에서 타입을 알아내는 기능 | TS의 추론 |
| 타입 표기 | 이름 뒤에 타입을 직접 쓰기 | `name: string` |
| 값 타입 | 복사되어 독립된 값을 만드는 타입 | 원시값과 유사하나 범위가 더 넓음 |
| 참조 타입 | 같은 인스턴스를 함께 가리키는 타입 | 객체 참조 |
| 문자열(String) | 문자들의 값 | `string` |
| 문자열 보간 | 문자열 안에 값을 삽입하기 | 템플릿 리터럴 |
| 정수(Int) | 소수점 없는 수 | `number`의 정수 사용 |
| 실수(Double) | 소수점을 표현하는 수 | `number` |
| 불리언(Bool) | 참 또는 거짓 | `boolean` |
| 배열(Array) | 순서 있는 같은 타입 값 모음 | `T[]` |
| 딕셔너리(Dictionary) | 키와 값의 모음 | `Map` 또는 `Record` |
| 집합(Set) | 중복 없는 값 모음 | `Set` |
| 튜플(tuple) | 위치별 타입이 정해진 묶음 | TS 튜플 |
| 열거형(enum) | 가능한 경우를 닫힌 집합으로 표현 | TS enum/구별 유니온 |
| 연관 값 | enum의 각 경우가 품는 데이터 | 구별 유니온의 필드 |
| 조건문 | 조건에 따라 코드 선택 | `if` |
| switch | 여러 경우를 빠짐없이 분기 | `switch` |
| 삼항 연산자 | 조건에 따른 두 값 선택 | `a ? b : c` |
| 범위(range) | 시작과 끝을 나타내는 값 | 직접 대응 없음 |
| 반복문(loop) | 값을 차례로 처리 | `for...of` |
| 함수(function) | 입력을 받아 작업하고 반환 | 함수 |
| 매개변수(parameter) | 함수 정의의 입력 이름 | 매개변수 |
| 인수(argument) | 호출할 때 전달하는 값 | 인수 |
| 인수 레이블 | 호출부에서 쓰는 매개변수 이름 | 객체 인수와 비슷한 읽기 효과 |
| 반환값 | 함수 호출의 결과 | `return` 값 |
| 기본 매개변수 | 생략 시 사용할 값 | 기본 매개변수 |
| 가변 매개변수 | 여러 인수를 배열처럼 받기 | rest parameter |
| throwing 함수 | 실패를 오류로 던질 수 있는 함수 | `throw` 가능 함수 |
| do-catch | 던져진 오류 처리 | `try...catch` |
| Result | 성공과 실패를 값으로 표현 | 구별 유니온 |
| 클로저(closure) | 주변 값을 붙잡을 수 있는 함수 값 | 화살표 함수/클로저 |
| 후행 클로저 | 마지막 함수 인수를 중괄호 뒤에 쓰는 문법 | 콜백 인수와 유사 |
| 고차 함수 | 함수를 받거나 반환하는 함수 | `map`, `filter` |
| 구조체(struct) | 값 타입 데이터와 동작의 묶음 | 직접 대응 없음 |
| 프로퍼티(property) | 타입이 보관하거나 계산하는 값 | 객체 속성/getter |
| 저장 프로퍼티 | 실제로 저장되는 값 | 일반 필드 |
| 계산 프로퍼티 | 접근할 때 계산되는 값 | getter |
| 프로퍼티 옵저버 | 값 변경 전후에 실행되는 코드 | setter/반응 효과와 유사 |
| 메서드(method) | 타입에 속한 함수 | 객체 메서드 |
| mutating | 값 타입의 내부 변경을 허용하는 표시 | 직접 대응 없음 |
| 이니셜라이저 | 인스턴스 초기 상태를 만드는 함수 | constructor |
| self | 현재 인스턴스 | `this` |
| 접근 제어 | 외부에서 볼 수 있는 범위 제한 | `private`, `public` |
| static | 타입 자체에 속한 멤버 | `static` |
| 클래스(class) | 참조 타입 데이터와 동작의 묶음 | JS class |
| 상속(inheritance) | 부모 클래스의 기능을 물려받기 | `extends` |
| override | 부모 구현을 바꾸어 제공 | `override` 개념 |
| final | 상속이나 재정의를 막기 | 직접 대응 없음 |
| 디이니셜라이저 | 인스턴스 해제 직전 실행 | 안정적 직접 대응 없음 |
| 프로토콜(protocol) | 필요한 속성과 동작의 계약 | TS interface |
| 확장(extension) | 기존 타입에 기능을 덧붙이기 | prototype 확장과 목적은 비슷하나 안전성이 다름 |
| 제네릭(generic) | 타입을 매개변수로 받기 | `<T>` |
| 옵셔널(optional) | 값이 있거나 `nil`일 수 있는 타입 | `T | undefined`와 유사 |
| nil | 값이 없음 | `null`/`undefined`와 유사 |
| 옵셔널 바인딩 | 안전하게 값을 꺼내며 분기 | null 검사와 좁히기 |
| 강제 언래핑 | 값이 있다고 단정해 꺼내기 | non-null assertion `!` |
| nil 병합 | 값이 없을 때 기본값 선택 | `??` |
| guard | 조건 실패를 먼저 처리하고 종료 | early return |
| View | SwiftUI 화면 조각의 계약 | React 컴포넌트와 유사 |
| body | 뷰가 그릴 구조를 설명하는 프로퍼티 | 컴포넌트 반환 JSX와 유사 |
| 수정자(modifier) | 뷰를 감싸 모양·동작을 바꾸기 | props/CSS 조합과 비슷함 |
| 상태(state) | 화면 갱신의 원인이 되는 데이터 | React state |
| 바인딩(binding) | 상태를 읽고 쓸 수 있게 연결 | 값+setter를 넘기는 패턴 |
| 환경(environment) | 상위에서 공유되는 값 | React context와 유사 |
| NavigationStack | 화면 이동 경로를 관리하는 컨테이너 | 라우터 스택 |
| Form | 입력 화면을 구성하는 컨테이너 | HTML form과 목적 유사 |
| List | 행을 효율적으로 표시하는 뷰 | 리스트 렌더링 |
| ForEach | 데이터로 반복 뷰 생성 | 배열의 `map`과 유사 |
| Identifiable | 항목의 안정적인 식별자 계약 | React `key` 요구와 유사 |
| Codable | 인코딩·디코딩 가능한 타입 계약 | JSON 직렬화 타입 |
| Observable | 변화 관찰이 가능한 모델 | 반응형 store |
| 애니메이션 | 값 변화의 시각적 중간 상태 | CSS/웹 애니메이션 |
| 전환(transition) | 뷰 삽입·제거의 시각 효과 | enter/exit animation |
| 프리뷰(preview) | 여러 상태의 화면 미리보기 | Storybook과 유사 |
| 불투명 반환 타입 | 구체 타입을 숨기고 계약만 노출 | 제한적인 추상 반환형 |
